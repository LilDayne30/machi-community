# マネタイズで追加する画面の定義

2026-11-11。[マネタイズ一覧](monetization-overview.md) と [有料相談の仕様](paid-consultation-spec.md) を画面単位に落としたもの。実装はこの順（フェーズ1 → 2）で進める。共通ルールは `reusable-web-app-spec.md` 第7・8章（1画面1主操作、loading/success/empty/error/unauthorized、PC/モバイル、アクセシビリティ）に従う。

## 前提（決定済み）
- 決済はStripe（地域トークの Checkout・Webhook・返金処理を流用）。
- 経験者の有料相談：**30分 3,500円**（経験者 2,500円、Roamigo 1,000円）。固定価格。
- 有料相談を受けられるのは **18歳以上・運営承認済み** の経験者だけ。経験者への支払いは月末に運営が手動振込。
- 日程は既存の1対1チャットで調整（候補3つ）。通話は経験者が入れる Meet/Zoom のURL。
- 承認期限48時間、支払期限は承認から24時間、問題報告は実施後72時間。
- キャンセル：利用者が24時間前まで→全額返金／それ以降・無断欠席→返金なし／経験者都合→全額返金。
- エージェント送客料：1件 5,000〜6,000円、相談の受諾時に発生。最初は請求書で手動精算。
- 経験者がエージェント等から紹介料を受け取る仕組みは作らない。事業者は一般の人検索に出さず、相談してきた人とだけ会話できる（既存の `role!='provider'` 除外を維持）。

既存の画面：利用者 `/` `/people` `/people/:id` `/profile` `/rooms` `/rooms/:id` `/talks` `/talks/:id` `/notes` `/notes/:id` `/consult`。管理 `/` `/members` `/bookings` `/consultations` `/providers` `/talks` `/notes` `/reports` `/costs` `/emails` `/logs`。

## フェーズ1：経験者の有料相談

### 利用者サイト：変更する画面

| 画面 | 変更内容 |
|---|---|
| `/profile`（プロフィール編集） | 「留学経験を伝える」立場の中に、経験ごとの追加項目（都市、学校名＋公開/非公開、滞在先、エージェント利用の有無、費用の目安、語学レベル、大変だったこと・よかったこと）と、経歴（現在の所属、学歴・職歴の要約、相談できる言語）、外部記事リンク（3件まで）を追加。下部に「有料相談」ブロック：受付ON/OFF、受けられる曜日・時間帯、承認状態（未申請／確認待ち／承認済み／停止）と「確認を申請する」ボタン。 |
| `/people`（検索結果） | 承認済みかつ受付ONの経験者に「有料相談可」バッジ。絞り込みに「有料相談できる人」を追加。 |
| `/people/:id`（他人のプロフィール） | 追加項目の表示（非公開の学校名は出さない）、「運営確認済み」表示と注記（経験の内容を保証するものではない）、関連記事、主操作「有料相談を申し込む（30分 3,500円）」。無料の「メッセージを送る」は残す。 |
| `/rooms/:id`（1対1の会話） | 相手が有料相談可なら申込ボタン。申込・承認・支払い・確定・キャンセル等を会話内のカードで表示し、カードから次の操作へ進める。 |
| `/`（ホーム） | 対応が必要な有料相談（承認待ち・支払い待ち・まもなく開始）があれば1件だけ案内する。 |

### 利用者サイト：新しい画面

| URL | 役割 | 主操作 | 主な内容・ルール |
|---|---|---|---|
| `/people/:id/session/new` | 有料相談の申込 | 申し込む | 相談したいこと（10〜1,000字）、候補日時3つ、料金・キャンセル規定の表示、18歳未満は保護者同意チェック必須。支払いはまだ発生しないと明示。 |
| `/sessions` | 自分の有料相談の一覧 | 個別へ進む | タブ：申し込んだ相談／受けた相談（経験者のみ）。状態ごとに並べ、対応が必要なものを上に。空状態の案内あり。 |
| `/sessions/:id` | 有料相談の詳細 | 状態に応じて1つ | 状態ごとの主操作：経験者＝承認（候補から日時を選び通話URLを入力、httpsのみ）／辞退、利用者＝支払う（Stripeへ）、両者＝キャンセル（規定と返金額を確認画面で表示）、開始時刻前後＝通話を開く、経験者＝実施した、利用者＝問題を報告（72時間以内）。期限と残り時間を表示。 |
| `/sessions/:id/paid` | 支払い完了 | 詳細へ戻る | Stripeから戻った先。Webhookで確定するまで「確認中」を表示し、確定後に日時・通話URLを案内。 |
| `/advisor/apply` | 有料相談の確認申請 | 申請する | 18歳以上の確認（生年月日）、在籍・修了がわかる書類のアップロード（運営だけが見る、確認後に削除）、経験者規約への同意（直接取引・紹介料の禁止、キャンセル規定、月末振込、所得の扱いの案内）。口座情報はアプリに保存しない（承認後に別途案内）。 |
| `/advisor/earnings` | 経験者の収入 | （閲覧のみ） | 月ごとの実施件数・支払予定額・支払済み額。精算の流れの説明。 |
| `/legal/tokushoho` | 特定商取引法に基づく表記 | — | 事業者名・連絡先等は Dan が確定するまでプレースホルダ。地域トークと有料相談の料金・支払時期・キャンセルを記載。 |
| `/legal/terms` | 利用規約（有料相談・経験者規約の章を追加） | — | 既存の規約があれば章を追加。文面は仮置きで、確定は Dan。 |

### 管理サイト：変更・新しい画面

| URL | 役割 | 主操作 |
|---|---|---|

| `/payouts`（新規） | 月末の精算 | 月を選ぶと経験者ごとの支払額一覧。CSV書き出し、振込後に「支払済み」にする。 |
| `/notes`（変更） | 経験者本人の体験記・外部リンクの確認 | 公開／差し戻し。 |
| `/members`（変更） | 会員詳細に有料相談の承認状態と実績を表示 | — |
| `/`（変更） | ダッシュボードに有料相談の件数（申込→承認→支払→実施→返金）と売上・支払予定額を追加 | — |

### データ（参考）
- 新テーブル `paid_sessions`、`advisor_profiles`（受付・承認・確認日・確認者。本人は承認系を書き換えられない）。経験の追加項目は `users.profile.participation.experiences` に足す。体験記は `notes` を流用。
- 状態：`requested → accepted → paid → completed → settled`、分岐 `declined / expired / cancelled / refund_pending / refunded / disputed`。期限切れは読み込み時に判定（地域トークの bookings と同じ方式）。

## 後回し（このファイルの範囲外）
成約報酬、プロ相談の手数料と自動送金（Stripe Connect）、有料機能（月額／30日パス）、保護者向けセット、学校・団体向け、月額掲載、PR表示、レビュー、予約カレンダー。

## 受入条件（フェーズ1）
- 申込 → 承認 → 支払い（Stripeテストモード）→ 実施 → 72時間後の精算対象化、までをブラウザテストで通す。キャンセル3パターンと問題報告→管理画面での解決も通す。
- 期限切れ（承認48時間・支払24時間）が自動で反映される。
- 未承認・18歳未満・停止中の経験者は申込を受けられない。他人の相談・書類・収入は見られない（APIで403）。
- 非公開の学校名・確認書類が公開APIに出ない。
- PCと幅320pxで表示崩れがなく、axeの重大な違反がない。
- 既存の地域トークの決済・Webhookのテストが引き続き通る。
